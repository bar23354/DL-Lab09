# DL-Lab09

Pronóstico day-ahead del consumo eléctrico horario de 317 clientes de Portugal (ElectricityLoadDiagrams20112014).

Roberto Barreda 23354, Mia Fuentes 23775

## Contenido

`Lab09_Series_de_Tiempo.ipynb` notebook con carga, limpieza, exploración, Dataset de ventanas, auditoría de fugas, backtest y modelos.

`informe/` informe en Word y PDF, y el script que lo genera.

`figuras/` gráficas exportadas por el notebook.

## Uso

```
pip install -r requirements.txt
jupyter notebook Lab09_Series_de_Tiempo.ipynb
```

El notebook descarga los datos de UCI en `data/` la primera vez.
